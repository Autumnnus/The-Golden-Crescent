# The Golden Crescent

Victoria 3 için alternatif tarih modu. Ortak Atlas ve Flavor kodu **ayrı `vic3-mod-tools` reposunda** tutulur; bu repo yalnız mod kaynaklarını ve kısa bağlantı betiklerini içerir.

**Başlat:** `Tools.command` dosyasına çift tıkla. Menüde **1 Atlas**, **2 Flavor**. Windows: `scripts/Tools.bat`; terminal: `sh scripts/tools.sh`.

- [Araçları kullanma / yeniden bağlama](docs/TOOLS.md)
- [Ana senaryo](docs/scenario/senaryo.md), [Afrika](docs/scenario/senaryo_afrika.md), [Amerika](docs/scenario/senaryo_amerika.md)
- [State notları](docs/reference/states.md)
- LLM yönergesi: [AGENTS.md](AGENTS.md)

`world/`: etkin başlangıç dünyası. `flavor/projects/`: hikâye planları. `build/`: yalnız bu modun önbellek ve önizlemeleri. `docs/archive/`: tarihsel belgeler; çalıştırılacak güncel talimatlar değildir.
