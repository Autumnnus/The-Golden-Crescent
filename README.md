# The Golden Crescent

Victoria 3 için alternatif tarih modu. Ortak Atlas ve Flavor kodu **ayrı `vic3-mod-tools` reposunda** tutulur; bu repo yalnız mod kaynaklarını ve kısa bağlantı betiklerini içerir.

**Başlat:** `Tools.command` dosyasına çift tıkla. Menüde **1 Atlas**, **2 Flavor**. Windows: `scripts/Tools.bat`; terminal: `sh scripts/tools.sh`.
